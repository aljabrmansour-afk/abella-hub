# نظام أبيلا للمناسبات

منظومة رقمية متكاملة لإدارة شركة أبيلا للمناسبات، تشمل:
- لوحة تحكم إدارية على المتصفح
- تطبيق جوال (PWA) للفرق الميدانية
- نظام مخزون ذكي بالباركود
- إدارة دورة حياة المناسبة كاملة من العميل إلى الإقفال المالي

---

## التشغيل السريع

### الشرط الوحيد
- **Python 3.7 أو أعلى** (مثبت غالبًا في معظم الأجهزة)

### خطوات التشغيل

1. افتح موجه الأوامر (Command Prompt أو PowerShell على ويندوز / Terminal على ماك)

2. انتقل إلى مجلد المشروع:
   ```
   cd "مسار_المجلد/abela_system"
   ```

3. شغّل الخادم:
   ```
   python backend/server.py
   ```

   أو على ماك/لينكس:
   ```
   python3 backend/server.py
   ```

4. افتح المتصفح على:
   - **لوحة التحكم:** http://localhost:8080/
   - **تطبيق الجوال:** http://localhost:8080/mobile/

## الموديولات الجاهزة

### ١. لوحة المعلومات
- إحصائيات لحظية: المناسبات النشطة، الإيرادات، المخزون، المتأخرات
- المناسبات القادمة في نظرة سريعة

### ٢. إدارة المناسبات
- دورة حياة كاملة: استفسار → عرض سعر → تعاقد → تخطيط → تنفيذ → إقفال
- ربط بالعميل، الفريق، المخزون، المهام، الدفعات
- بحث وفلترة بالحالة

### ٣. إدارة العملاء (CRM)
- قاعدة عملاء كاملة مع التفضيلات والملاحظات الحساسة
- تصنيف (فرد / VIP / شركة)
- تاريخ المناسبات لكل عميل

### ٤. المخزون الذكي
- باركود/QR لكل قطعة
- تتبع الموقع والحالة المادية
- سجل كامل للحركات
- تنبيه القطع المتضررة/المفقودة

### ٥. الفرق
- ٩ فرق (خدمة عملاء، تعاقد، مالية، إشراف، تنفيذ، ضيافة، مصنع، مستودعين)
- توزيع الأدوار وتكليفات المناسبات

### ٦. المالية والربحية
- متابعة الدفعات والمتأخرات
- حساب هامش ربح كل مناسبة لحظيًا
- تقارير مالية تفصيلية

### ٧. التقارير التحليلية
- توزيع المناسبات حسب النوع
- أكثر القطع استخدامًا
- مؤشرات الأداء

### ٨. تطبيق الفرق الميدانية (PWA)
- يثبّت على الجوال زي التطبيق العادي
- ماسح باركود مدمج (يستخدم كاميرا الجوال)
- خروج/إرجاع المخزون بمسحة
- متابعة المهام: ابدأ ✓ أنجز ✓ متضرر ⚠️ مفقود ❌
- يعمل أوفلاين

## كيف يستخدم الفرق التطبيق على الجوال؟

١. الموظف يفتح **http://[عنوان-السيرفر]:8080/mobile/** على متصفح جواله
٢. يضغط على القائمة → "إضافة إلى الشاشة الرئيسية"
٣. يصبح التطبيق أيقونة مستقلة على جواله
٤. تسجيل الدخول مرة واحدة، بعدها يفتح مباشرة

## دور كل فريق في النظام

| الفريق | يستخدم | أهم عملياته |
|-------|--------|-------------|
| خدمة العملاء | لوحة التحكم | إنشاء العملاء، فتح المناسبات الجديدة |
| التعاقد | لوحة التحكم | تحديث الأسعار، تغيير الحالة لـ "متعاقد" |
| المالية | لوحة التحكم | إضافة دفعات، تقارير الربحية |
| الإشراف | كلاهما | جدولة المناسبات، توزيع الفرق، متابعة الجودة |
| التنفيذ الميداني | تطبيق الجوال | المهام، خروج/إرجاع المخزون، صور |
| الضيافة | تطبيق الجوال | متابعة مهام الضيافة |
| المصنع | لوحة التحكم | أوامر التصنيع |
| المستودعات | تطبيق الجوال | استلام/تسليم بالباركود |

## ملاحظات أمنية مهمة قبل الاستخدام الفعلي

1. **غيّر كلمات المرور الافتراضية فورًا** قبل الاستخدام الفعلي
2. عدّل ملف `backend/server.py` وغيّر `PORT` و `HOST` حسب احتياجك
3. للنشر على الإنترنت: استخدم HTTPS (شهادة SSL مجانية من Let's Encrypt)
4. خذ نسخة احتياطية يومية من `backend/db/abela.db`
